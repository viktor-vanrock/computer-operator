# Custom OS Image Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let `frontend-tech` users type a custom VM Fleet image id instead of picking a preset OS; the backend then creates a fresh VM on demand (VM Provisioning) instead of reserving one from the existing pool (VM Reservation), and connects to it once it's ready.

**Architecture:** `VMFleetClient` gains two new composable methods (`createCustomDeployment`, `waitDeploymentReady`/`waitCustomVmReady`) alongside the existing `reserveAvailable`. `sessions.service.ts`'s `startAgent` is split into a shared tail (`_completeVmAcquisition`) plus two strategy-specific heads: `_startWithPresetOs` (unchanged, synchronous) and `_startWithCustomImage` (new, asynchronous — kicks off in the background and returns immediately, mirroring the existing `schedulePreparingTimeout`/`deleteVmSilent` fire-and-forget pattern). Because provisioning is async, `connectArgs` can no longer be assumed present in `POST /start`'s response — it's added to the `STATUS_CHANGE` WS event instead.

**Tech Stack:** Fastify + Zod + Prisma (backend), React + TanStack Query (frontend-tech), Vitest (backend + frontend-demo only — frontend-tech has no test runner).

**Spec:** `docs/superpowers/plans/2026-08-31-custom-os-image-spec.md` (also read `CONTEXT.md` and `docs/adr/0001-custom-image-vm-provisioning-shares-reserved-vm-profile.md` at the repo root).

## Global Constraints

- `customImageId` format: `^[a-zA-Z0-9._-]{1,100}$`, enforced by Zod, rejected with 400 otherwise.
- VM Fleet profile for provisioning: constant `reserved_vm` (same as the Preset OS pool). Generated VM name: `reserved_vm_<customImageId>_<uuid-no-dashes>`.
- `VM_FLEET_DEPLOYMENT_TIMEOUT_MS = 3 * 60_000`, `VM_FLEET_DEPLOYMENT_POLL_INTERVAL_MS = 2_000`.
- Feature scope: `SOLO` and `FULL_DUPLEX` in `frontend-tech` only. `SPLIT` is untouched — no guard, no UI.
- VM Reservation (Preset OS) stays synchronous inside `POST /sessions/:id/start`. VM Provisioning (Custom OS Image) is asynchronous — fire-and-forget from `startAgent`, completing via the existing status+WS-broadcast mechanism.
- `Session.vmName` is persisted immediately after `POST /api/v1/deployments` succeeds, before polling for readiness.
- Failure reason taxonomy exactly as listed in the spec's table — `openTask` failures stay `AGENT_START_FAILED`, untouched.
- `STATUS_CHANGE` WS events gain an optional `connectArgs` field, populated on transition to `PREPARING`.
- All imports use `@/` (within an app) or `@arena/ui/*` (shared package) aliases, never relative `../`.
- No `any`/`unknown` in new code; every new function/method is fully typed.
- Russian for all UI copy and code comments where comments are warranted (sparingly — only for non-obvious WHY).

```ts
  async createCustomDeployment(imageId: string): Promise<{ vmName: string; deploymentId: string }> {
    const vmName = `${VM_FLEET_RESERVED_PROFILE}_${imageId}_${randomUUID().replace(/-/g, '')}`;
    const idempotencyKey = randomUUID();

    const response = await this.request('/api/v1/deployments', {
      method: 'POST',
      headers: { 'Idempotency-Key': idempotencyKey },
      body: JSON.stringify({ profile: VM_FLEET_RESERVED_PROFILE, image: imageId, name: vmName }),
    });
    const created = await this.readJson<{ deployment_id: string }>(response);

    return { vmName, deploymentId: created.deployment_id };
  }

  async waitDeploymentReady(
    deploymentId: string,
    timeoutMs = VM_FLEET_DEPLOYMENT_TIMEOUT_MS,
    pollIntervalMs = VM_FLEET_DEPLOYMENT_POLL_INTERVAL_MS
  ): Promise<VMFleetDeployment> {
    const deadline = Date.now() + timeoutMs;
    while (Date.now() < deadline) {
      const response = await this.request(`/api/v1/deployments/${encodeURIComponent(deploymentId)}`, {
        method: 'GET',
        retryTimeout: true,
      });
      const deployment = await this.readJson<VMFleetDeployment>(response);

      if (deployment.queued === 0 && deployment.in_progress === 0) {
        if (deployment.failed === 0 && deployment.ready === deployment.requested) {
          return deployment;
        }
        throw new VMFleetApiError(
          `VM Fleet deployment ${deploymentId} failed: ${deployment.failed} of ${deployment.requested} VM(s) failed`,
          undefined,
          'deployment_failed'
        );
      }
      await sleep(pollIntervalMs);
    }
    throw new VMFleetApiError(`Timed out waiting for deployment ${deploymentId} to become ready`, undefined, 'deployment_timeout');
  }

  async waitCustomVmReady(
    deploymentId: string,
    vmName: string,
    timeoutMs = VM_FLEET_DEPLOYMENT_TIMEOUT_MS,
    pollIntervalMs = VM_FLEET_DEPLOYMENT_POLL_INTERVAL_MS
  ): Promise<ReservedVm> {
    const deployment = await this.waitDeploymentReady(deploymentId, timeoutMs, pollIntervalMs);
    const vm = deployment.vms.find((v) => v.name === vmName);
    if (!vm) {
      throw new VMFleetApiError(`VM Fleet deployment ${deploymentId} has no VM named ${vmName}`);
    }
    return this.toReservedVm(vm);
  }

  private toReservedVm(vm: VMFleetVm): ReservedVm {
    return {
      vmId: vm.id,
      vmName: vm.name,
      status: vm.actual_state,
      connectionId: String(vm.guacamole_connection_id),
      ...(vm.private_ip && { ipAddress: vm.private_ip }),
    };
  }
```

```ts
  async startAgent(id: string): Promise<Session> {
    const session = await this.findById(id);

    if (session.status !== SESSION_STATUSES.PENDING) {
      log.warn({ sessionId: id }, 'session has already been started');
      throw new BadRequestException('Session has already been started', 'SESSION_ALREADY_STARTED');
    }

    if (session.mode === 'SPLIT') {
      return this._startSplitAgents(id, session);
    }

    if (!session.arenaOs) throw new BadRequestException('arenaOs is required', 'ARENA_OS_MISSING');

    return this._startWithPresetOs(id, session);
  },

  async _startWithPresetOs(id: string, session: Session): Promise<Session> {
    const agentStartedAt = Date.now();

    let vmName: string | undefined;
    let guacId: string | undefined;
    try {
      const vmResult = await vmFleetClient.reserveAvailable(session.arenaOs!);
      vmName = vmResult.vmName;
      guacId = vmResult.connectionId;
      await prisma.session.update({ where: { id }, data: { vmName, guacId } });
    } catch (err) {
      if (vmName) vmFleetClient.releaseReservation(vmName);
      log.error({ vmName, guacId, sessionId: id, err }, 'VM Fleet reservation failed');
      pendingMaxSteps.delete(id);
      sessionsFailedTotal.inc({ reason: FAILURE_REASONS.VM_RESERVATION_EXHAUSTED });
      await this.setStatus(id, SESSION_STATUSES.FAILED);
      broadcast(id, { type: WS_EVENT_TYPES.STATUS_CHANGE, payload: { status: SESSION_STATUSES.FAILED } });
      const { message } = err as Error;
      throw new BadRequestException(message, FAILURE_REASONS.VM_RESERVATION_EXHAUSTED);
    }

    return this._completeVmAcquisition(id, vmName, guacId, agentStartedAt);
  },

  async _completeVmAcquisition(id: string, vmName: string, guacId: string, agentStartedAt: number): Promise<Session> {
    let connectArgs: string;
    try {
      log.info({ sessionId: id, step: 'getAuthToken' }, 'pipeline: getting Guacamole auth token');
      const authToken = await guacamoleClient.getAuthToken();
      pendingGuacTokens.set(id, authToken);
      connectArgs = guacamoleClient.buildConnectArgs(authToken, guacId);
      log.info({ sessionId: id, step: 'buildConnectArgs' }, 'pipeline: connectArgs built, saving to DB');
    } catch (err) {
      log.error({ sessionId: id, err, step: 'getAuthToken' }, 'pipeline: Guacamole auth failed');
      pendingGuacTokens.delete(id);
      pendingMaxSteps.delete(id);
      sessionsFailedTotal.inc({ reason: FAILURE_REASONS.GUACAMOLE_AUTH_FAILED });
      await this.setStatus(id, SESSION_STATUSES.FAILED);
      broadcast(id, { type: WS_EVENT_TYPES.STATUS_CHANGE, payload: { status: SESSION_STATUSES.FAILED } });
      deleteVmSilent(vmName, id);
      const { message } = err as Error;
      throw new BadRequestException(message, FAILURE_REASONS.GUACAMOLE_AUTH_FAILED);
    }

    log.info({ sessionId: id, step: 'PREPARING' }, 'pipeline: saving connectArgs, status → PREPARING');
    const authToken = pendingGuacTokens.get(id);
    const updated = await (async () => {
      const session = await prisma.session.update({
        where: { id },
        data: { connectArgs, guacAuthToken: authToken ?? null, status: SESSION_STATUSES.PREPARING },
        include: { metrics: true },
      });
      return serialize(session as unknown as RawSession);
    })();
    broadcast(id, { type: WS_EVENT_TYPES.STATUS_CHANGE, payload: { status: SESSION_STATUSES.PREPARING, connectArgs } });
    schedulePreparingTimeout(id);

    agentStartDurationSeconds.observe((Date.now() - agentStartedAt) / 1000);
    return updated;
  },
```

```ts
  async _startWithCustomImage(id: string, session: Session): Promise<void> {
    const agentStartedAt = Date.now();

    let vmName: string;
    let deploymentId: string;
    try {
      const created = await vmFleetClient.createCustomDeployment(session.customImageId!);
      vmName = created.vmName;
      deploymentId = created.deploymentId;
      // Персистим имя сразу после успешного POST — если backend упадёт во время
      // ожидания готовности ниже, VM останется обнаружимой по этому имени в VM Fleet.
      await prisma.session.update({ where: { id }, data: { vmName } });
    } catch (err) {
      log.error({ sessionId: id, err }, 'VM Fleet: deployment creation rejected');
      pendingMaxSteps.delete(id);
      sessionsFailedTotal.inc({ reason: FAILURE_REASONS.VM_PROVISIONING_REJECTED });
      await this.setStatus(id, SESSION_STATUSES.FAILED);
      broadcast(id, { type: WS_EVENT_TYPES.STATUS_CHANGE, payload: { status: SESSION_STATUSES.FAILED } });
      return;
    }

    let guacId: string;
    try {
      const ready = await vmFleetClient.waitCustomVmReady(deploymentId, vmName);
      guacId = ready.connectionId;
      await prisma.session.update({ where: { id }, data: { guacId } });
    } catch (err) {
      const isTimeout = err instanceof VMFleetApiError && err.apiCode === 'deployment_timeout';
      log.error({ sessionId: id, vmName, deploymentId, err }, 'VM Fleet: provisioning did not become ready');
      pendingMaxSteps.delete(id);
      sessionsFailedTotal.inc({ reason: isTimeout ? FAILURE_REASONS.VM_PROVISIONING_TIMEOUT : FAILURE_REASONS.VM_PROVISIONING_FAILED });
      await this.setStatus(id, SESSION_STATUSES.FAILED);
      broadcast(id, { type: WS_EVENT_TYPES.STATUS_CHANGE, payload: { status: SESSION_STATUSES.FAILED } });
      deleteVmSilent(vmName, id);
      return;
    }

    await this._completeVmAcquisition(id, vmName, guacId, agentStartedAt);
  },
```
