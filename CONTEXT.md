# UI-Agent Arena

Демо-платформа, где человек и ИИ-агент выполняют задания в UI одной и той же виртуальной машины, а результаты сравниваются. Ниже — термины, специфичные для домена сессий и управления виртуальными машинами (VM Fleet).

## Language

### Настройка сессии

**Preset OS**:
Заранее сконфигурированный образ ОС из фиксированного списка (`OS_OPTIONS`, сейчас только `ubuntu2204`), под который VM Fleet держит пул уже готовых машин.
_Avoid_: ОС сессии, arenaOs (как термин в прозе — это только имя поля)

**Custom OS Image**:
Идентификатор Packer-образа VM Fleet, который пользователь выбирает в общем списке вместе с Preset OS. Список строится по используемым образам VM Fleet с метаданными `tags`. При выборе полностью заменяет Preset OS для этой сессии. Доступен в SOLO и FULL_DUPLEX режимах тех-сервиса (`frontend-tech`). Резервируется тем же способом, что и Preset OS — см. VM Reservation.
_Avoid_: кастомная ОС, custom image

### VM Fleet

**VM Reservation**:
Получение уже существующей готовой машины из пула VM Fleet (`GET /api/v1/vms?image=<value>`) — единственный способ получения VM для сессии, независимо от того, задан Preset OS или Custom OS Image. Значение `image` для Preset OS берётся из `DEFAULT_IMAGE_BY_OS`, для Custom OS Image — это полный идентификатор выбранного образа.
_Avoid_: резервирование, allocation, VM Provisioning (устаревший термин — см. ADR 0001)
